measured_error_scale¶

strider.preprocess.measured_error_scale(wavelength, flux, error, mask=None, minimum=20)[source]¶

The factor by which the visits’ scatter exceeds their stated errors, never below 1.

It compares each pixel with its neighbours two pixels either side, as DER_SNR does (Stoehr et al. 2008). Pixels that are masked, not finite, or brighter than about 10 errors are left out; it returns 1 if fewer than minimum comparisons remain. Noise correlated between neighbouring pixels makes it read low.

Parameters:

  • wavelength – The visits, as prepare takes them.

  • flux – The visits, as prepare takes them.

  • error – The visits, as prepare takes them.

  • mask – The visits, as prepare takes them.

  • minimum (int) – The fewest comparisons to measure from.

Return type:

float
