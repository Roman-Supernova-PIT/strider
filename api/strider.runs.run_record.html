run_record¶

strider.runs.run_record(model, priors=None, source=None, job=None, workers=1, error_scale=1.0, light_curve_errors='check', max_spectra=None) → dict[source]¶

The record of a run: the model, the settings that change results, the input, the job and each session’s environment.

priors are the user’s priors as strider.Model.classify_many takes them, and source describes the input: its path and sha256, the only objects chosen from it, and the columns, wavelength_unit and flux_density it was read with. The settings_fingerprint covers the model, the STRIDER and schema versions and the settings, not the input, the job or the environment.
