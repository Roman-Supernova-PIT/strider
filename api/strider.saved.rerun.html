rerun¶

strider.saved.rerun(path, model=None) → tuple[list[str], list[str]][source]¶

Classify a saved transient again with its run’s model and settings, and compare with its saved result.

Parameters:

  • path (path-like) – A saved transient’s folder (save_transient).

  • model (strider.Model, optional) – The model to use; by default the saved run’s, by name, with its scan.

Returns:

  • differences (list of str) – How the result differs, empty if it is the same within TOLERANCE.

  • environment (list of str) – How the versions and the machine differ from the run’s, which can explain small differences.
