results_table¶

strider.io.results_table(results: dict[str, Classification | str], model, summary: bool = False)[source]¶

Return a pyarrow table of results, with one row per object.

results maps each object id to its strider.Classification, or to the reason it could not be classified. Reading the results lists the columns. A summary table (results_schema) is the one a CSV file holds.
