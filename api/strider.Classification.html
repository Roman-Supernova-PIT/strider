Classification¶

class strider.Classification(model: str, fingerprint: str, class_probabilities: dict[str, float], equal_prior_probabilities: dict[str, float], p_ia: float, redshift: float, redshift_probability: float, redshift_peaks: list[tuple[float, float]], redshift_68: tuple[float, float], redshift_95: tuple[float, float], redshift_grid: ~numpy.ndarray, redshift_cell_widths: ~numpy.ndarray, redshift_posterior: ~numpy.ndarray, class_redshift_posterior: ~numpy.ndarray, class_redshifts: dict[str, float], log_evidence: ~numpy.ndarray, source_probability: float | None, untrained_share: float, trained_classes: list[str], flags: dict[str, bool | None], best_match: tuple[str, float], next_best_class: str, match_gap: float, match_strength: str, warnings: list[str], visits_used: list[int], days_observed: float, signal_to_noise: float, dropped_visits: dict[int, str] = <factory>, error_scale: float = 1.0, redshift_range: tuple[float, float] | None = None)[source]¶

Bases: object

The result for one transient. Reading the results explains each field.

print(result) prints its card (card), and result.plot() draws its figure.

Parameters:

  • model (str) – The model’s name, and a code that identifies it: its network, brightness term, priors and settings.

  • fingerprint (str) – The model’s name, and a code that identifies it: its network, brightness term, priors and settings.

  • class_probabilities (dict of str to float) – The probability of each class.

  • equal_prior_probabilities (dict of str to float) – The class probabilities if every class were equally common.

  • p_ia (float) – The probability of a type Ia supernova.

  • redshift (float) – The redshift at the main peak of redshift_posterior: where the most probability lies within 0.1.

  • redshift_probability (float) – The probability that the true redshift is within 0.1 of redshift.

  • redshift_peaks (list of tuple of float) – Each distinct peak of redshift_posterior as (redshift, probability within 0.1 of it), the main one first.

  • redshift_68 (tuple of float) – The central 68% and 95% intervals of the redshift.

  • redshift_95 (tuple of float) – The central 68% and 95% intervals of the redshift.

  • redshift_grid (numpy.ndarray) – The centre and width of each redshift cell.

  • redshift_cell_widths (numpy.ndarray) – The centre and width of each redshift cell.

  • redshift_posterior (numpy.ndarray) – The probability that the redshift is in each cell. It sums to 1. Divide by the cell widths to get a density.

  • class_redshift_posterior (numpy.ndarray) – (classes, cells) the redshift posterior if the transient is of each class, in the order of class_probabilities; NaN for a class with no posterior at the redshifts allowed. redshift_given summarises one.

  • class_redshifts (dict of str to float) – The redshift at the main peak of each class’s redshift posterior, NaN for a class with no posterior at the redshifts allowed.

  • log_evidence (numpy.ndarray) – (classes, cells) the evidence map: the log evidence for each class and redshift cell, before any prior. It is -inf where the model had no training transients. Adding the log of a prior probability of each cell and normalising gives the posterior over the cells the model was trained on.

  • source_probability (float or None) – The probability that the visits hold a transient at all. None if the model has no source probability.

  • untrained_share (float) – The probability that the transient is of a subtype the model never saw at that redshift, within a class it did see there. Always 0 for a model with one subtype per class.

  • trained_classes (list of str) – The classes the model had training transients of at the redshift shown.

  • flags (dict of str to bool) – weak_source, several_redshift_peaks, untrained_subtypes, few_classes_trained and brightness_failed (the brightness term could not be computed, so the result uses the spectra alone). weak_source is None if the model has no source probability.

  • best_match (tuple of str and float) – The class and redshift that match the data best, before any prior.

  • next_best_class (str) – The best other class, at its own best redshift.

  • match_gap (float) – How far the best match is ahead of the next-best class, in log units; not a probability.

  • match_strength (str) – high, medium or low, from the match gap at levels fixed with the model.

  • warnings (list of str) – Why the best match may be less clear than its strength says.

  • visits_used (list of int) – The position in the input of each visit used, counting from 0, in time order.

  • days_observed (float) – The observer-frame days from the first visit used to the last.

  • signal_to_noise (float) – The median S/N per pixel of the visits used, combined on their own pixels.

  • dropped_visits (dict of int to str) – The reason each visit was left out, by its position in the input.

  • error_scale (float) – The factor the errors were multiplied by before classifying (error_scale of strider.Model.classify, measured if it was "auto"); 1 if they were used as given.

  • redshift_range (tuple of float or None) – The redshift range the result was restricted to (redshift_range of strider.Model.classify), or None. The redshifts and intervals then lie inside it.

Methods Summary

card([name])

Return the result as a short card: the most likely classes, the redshift and its 68% range, the match strength and any warnings, the data, and any checks that need attention.

plot([path, name])

Draw the result's figure: the spectra and their combination, the best-matching references of the two most likely classes, each visit's brightness in the four bands against SN Ia's light curves fitted to it, every class at every redshift, and the class probabilities and the redshift posterior of SN Ia and of the other classes.

redshift_given(name)

Return the redshift if the transient is of class name: its main peak, its central 68% and 95% intervals, and its posterior.

to_dict()

Return the result as a dictionary that json.dumps can write, without the evidence map.

plot(path: str | PathLike | None = None, name: str | None = None)[source]¶

Draw the result’s figure: the spectra and their combination, the best-matching references of the two most likely classes, each visit’s brightness in the four bands against SN Ia’s light curves fitted to it, every class at every redshift, and the class probabilities and the redshift posterior of SN Ia and of the other classes. Needs matplotlib (pip install "roman-snpit-strider[plot]").

Parameters:

  • name (str, optional) – A title for the figure.
