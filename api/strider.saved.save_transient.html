save_transient¶

strider.saved.save_transient(folder, key, transient, result, record, redshift_prior=None) → Path[source]¶

Save one transient in its own folder in folder (saved_folder), and return that folder. transient is its input, or the reason it could not be read (then the folder has no spectra); result its strider.Classification, or the reason it failed; and record its run’s (strider.runs.run_record).
