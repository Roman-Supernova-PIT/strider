Classify one transient and estimate its redshift.

Parameters:

  • data (strider.Transient, table, or sequence of numpy.ndarray) – The transient: a strider.Transient; a table with one row per pixel (strider.Transient.from_table); or the wavelength of each visit, in Å, with flux, error and mjd. If all visits share one wavelength grid, it can be that one array.

  • flux (sequence of numpy.ndarray, optional) – One array per visit: the flux per unit wavelength (f_λ), in any units, and its 1σ error in the same units.

  • error (sequence of numpy.ndarray, optional) – One array per visit: the flux per unit wavelength (f_λ), in any units, and its 1σ error in the same units.

  • mjd (sequence of float, optional) – The MJD of each visit, in days.

  • mask (sequence of numpy.ndarray or None, optional) – One array per visit, True for pixels to ignore. None uses every pixel.

  • host_redshift (float, optional) – A redshift prior from the host galaxy: its spectroscopic or photometric redshift and 1σ error. Give both or neither. They override any stored with the transient.

  • host_redshift_error (float, optional) – A redshift prior from the host galaxy: its spectroscopic or photometric redshift and 1σ error. Give both or neither. They override any stored with the transient.

  • classes (sequence of str, optional) – The only classes the transient can be. The probabilities are shared among them.

  • class_prior (mapping of str to float, optional) – How common each class is, before the data, in place of the model’s survey prior. Give a value for every class allowed; they need not sum to 1.

  • redshift_range (tuple of float, optional) – The lowest and highest redshift the transient can have.

  • redshift_prior (numpy.ndarray, optional) – A probability density for the redshift at each point of redshift_grid, such as a photometric redshift’s P(z), used as given.

  • host_redshift_outlier (float, optional) – The chance that the host redshift is wrong, such as a wrong host galaxy or a failed photometric redshift: that share of its weight is spread over every redshift, so strong data can overrule a wrong host. The default is 0.05; use about 0.03 for a spectroscopic host redshift.

  • error_scale (float or "auto") – A factor, from 0.001 to 1000, to multiply every visit’s errors by, for errors that understate the noise. "auto" measures it from the visits kept, never below 1 (strider.preprocess.measured_error_scale). The default, 1, uses the errors as given.

Return type:

Classify the first spectra in time order, for each number of spectra in steps: how the result builds up as the spectra arrive. Only spectra STRIDER can use count, so a spectrum it leaves out is skipped. Each number of spectra is one classify.

Parameters:

  • data – The transient, as classify takes it.

  • flux – The transient, as classify takes it.

  • error – The transient, as classify takes it.

  • mjd – The transient, as classify takes it.

  • mask – The transient, as classify takes it.

  • steps (sequence of int, optional) – The numbers of spectra, in increasing order, such as range(3, 9). By default 1, 2, 3, 5, 10 and 20 spectra, those fewer than all of them, then all; with more than 20, 2 is left out to keep six.

  • host_redshift – Your own priors, as classify takes them.

  • host_redshift_error – Your own priors, as classify takes them.

  • classes – Your own priors, as classify takes them.

  • class_prior – Your own priors, as classify takes them.

  • redshift_range – Your own priors, as classify takes them.

  • redshift_prior – Your own priors, as classify takes them.

  • host_redshift_outlier – Your own priors, as classify takes them.

  • error_scale (float or "auto") – As classify takes it; "auto" is measured from the spectra each step uses.

Returns:

The result of the first spectra, by their number. Each result’s visits_used gives the positions in the input of the spectra it used.

classify_many(objects: Mapping[str, Transient], output: str | PathLike | None = None, chunk: int = 100, plots: str | PathLike | None = None, *, evidence_maps: str | PathLike | None = None, redshift_curves: str | PathLike | None = None, workers: int = 1, batch: int | None = None, classes: Sequence[str] | None = None, class_prior: Mapping[str, float] | None = None, redshift_range: tuple[float, float] | None = None, redshift_prior: ndarray | None = None, host_redshift_outlier: float | None = None, error_scale: float | str = 1.0, keep: bool = True) → dict[str, Classification | str][source]¶

Classify many transients, and optionally write the results to a file.

Parameters:

  • objects (mapping of str to strider.Transient) – The transients by object id, as strider.io.read_spectra returns them.

  • output (str or path-like, optional) – The file to write the results to, ending in .parquet, .csv or .json (strider.io.write_results).

  • chunk (int) – How many objects to classify between writes to output.

  • plots (str or path-like, optional) – A folder to save each object’s figure in, as <object id>.png (strider.Classification.plot).

  • evidence_maps (str or path-like, optional) – Files to write the evidence maps (strider.io.EvidenceMapsFile, HDF5) and the redshift posteriors (strider.io.RedshiftCurvesFile, qp) to, written as the batch goes like output.

  • redshift_curves (str or path-like, optional) – Files to write the evidence maps (strider.io.EvidenceMapsFile, HDF5) and the redshift posteriors (strider.io.RedshiftCurvesFile, qp) to, written as the batch goes like output.

  • workers (int) – How many transients to classify at once, each in its own process on one CPU core. With several cores this is the fastest way through a batch on a CPU. In a script, call it under if __name__ == "__main__":.

  • batch (int, optional) – How many transients the network scores together. On a GPU this is the fast way through a batch; the default there is 8, and each transient in a batch needs about 1 GB of GPU memory. A batch that runs out of GPU memory is split in half and tried again. The default on a CPU is 1. The results are the same as one at a time, and on a GPU as on a CPU, up to float rounding. The brightness term runs on the CPU, one transient at a time.

  • classes (optional) – Your own priors, as classify takes them, for every object.

  • class_prior (optional) – Your own priors, as classify takes them, for every object.

  • redshift_range (optional) – Your own priors, as classify takes them, for every object.

  • redshift_prior (optional) – Your own priors, as classify takes them, for every object.

  • host_redshift_outlier (optional) – Your own priors, as classify takes them, for every object.

  • error_scale (float or "auto") – As classify takes it, for every object; "auto" is measured for each object from its own spectra.

  • keep (bool) – Keep every result in the returned dict. For a large batch written to files, keep=False keeps only the failures, so memory does not grow with the batch.

Returns:

  • dict – Each object’s result, by object id. If an object cannot be classified, its entry is the reason, as a string, and the batch carries on.

  • A batch that is stopped (Ctrl-C, or a scheduler’s SIGTERM) first writes the transients done. One that is

  • killed outright keeps, for a .parquet output, the transients written so far in <output>.parts.

Draw how the result builds up as the spectra arrive (classify_first). Each column shows the first spectra in time order: their combined spectrum and its S/N, the probability of each class at each redshift, and the redshift posterior of SN Ia and of the other classes, with P(Ia) and the main redshift. Needs matplotlib.

Parameters:

  • data – The transient, as classify takes it.

  • flux – The transient, as classify takes it.

  • error – The transient, as classify takes it.

  • mjd – The transient, as classify takes it.

  • mask – The transient, as classify takes it.

  • steps (sequence of int, optional) – How many spectra each column uses, as classify_first takes them.

  • path (str or path-like, optional) – A file to save the figure to, such as arrival.png.

  • name (str, optional) – A title for the figure.

  • true_redshift (float, optional) – A redshift to mark, such as a simulated transient’s true one.

  • rows (str) – "binary" gives two rows, SN Ia and the other classes summed; "all" gives a row for each class allowed.

  • host_redshift – Your own priors, as classify takes them.

  • host_redshift_error – Your own priors, as classify takes them.

  • classes – Your own priors, as classify takes them.

  • class_prior – Your own priors, as classify takes them.

  • redshift_range – Your own priors, as classify takes them.

  • redshift_prior – Your own priors, as classify takes them.

  • host_redshift_outlier – Your own priors, as classify takes them.

  • error_scale (float or "auto") – As classify_first takes it.

Return type:

matplotlib.figure.Figure
