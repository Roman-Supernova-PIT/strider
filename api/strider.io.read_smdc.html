read_smdc¶

strider.io.read_smdc(paths: list[str | PathLike], mjd: list[float], host_redshift: float | None = None, host_redshift_error: float | None = None) → Transient[source]¶

Read one transient from SMDC spectrum files, one file per visit. Reading them needs h5py.

Each file holds a visit’s wavelength in Å, flux and 1σ error as combined/data/lamb, flam and func. The files do not give the date, so give the MJD of each.
