fetch¶

strider.registry.fetch(name: str | None = None) → Path[source]¶

Return the local path of a released model package, downloading it if needed.

Parameters:

name (str, optional) – A model name, as strider models lists them, or "test" for the bundled test model. If left out, the default model.

Returns:

The downloaded package.

Return type:
