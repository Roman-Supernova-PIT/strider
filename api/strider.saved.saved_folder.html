saved_folder¶

strider.saved.saved_folder(folder, key) → Path[source]¶

The folder of one saved transient: its id, any character other than letters, digits, ‘.’, ‘-’ and ‘_’ replaced by ‘_’, then a short code of the id itself, so that different ids get different folders.
