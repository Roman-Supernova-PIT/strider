Parameters:

  • host_redshift (float, optional) – The host galaxy’s spectroscopic or photometric redshift and its 1σ error. Give both or neither.

classmethod from_table(table) → Transient[source]¶

Make a transient from a table with one row per pixel.

Parameters:

table (pandas.DataFrame, astropy.table.Table or dict of array_like) – The columns mjd, wavelength in Å, flux and error. Optional columns are mask, True for pixels to ignore, and host_redshift and host_redshift_error, the same on every row. The column time can stand for mjd, and flux_err or fluxerr for error; case does not matter. The rows with one MJD are one visit. Astropy columns with units are converted: wavelength to Å, flux and error to f_λ.

Return type:

strider.Transient
