load_model¶

strider.load_model(name: str | PathLike | None = None, device: str = 'cpu', sha256: str | None = None) → Model[source]¶

Load a model. A released model is downloaded the first time you use it.

Parameters:

  • name (str or path-like, optional) – A released model’s name (see strider models), "test" for the bundled test model, or the path to a model package. If left out, the default model.

  • device (str) – The PyTorch device to run on, cpu or cuda.

  • sha256 (str, optional) – For a package file given by path, its expected sha256: the file is refused if it differs. A released model is always checked against its own.

Return type:

strider.Model

Raises:

  • FileNotFoundError – If name looks like a path (it has a directory or ends in .tar.gz) and there is no package there.

  • ValueError – If name is not a released model, or STRIDER cannot read the package.
