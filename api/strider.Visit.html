Visit¶

class strider.Visit(wavelength: ndarray, flux: ndarray, error: ndarray, mjd: float, mask: ndarray | None = None)[source]¶

Bases: object

One visit: a prism spectrum of a transient at one date.

Parameters:

  • wavelength (numpy.ndarray) – Observer-frame wavelength in Å, on any grid. The visit should cover the model’s wavelength range, given on its model card; one up to 2% short of it at either end is used, and one further short is left out.

  • flux (numpy.ndarray) – Flux per unit wavelength (f_λ), in any units, and its 1σ error in the same units.

  • error (numpy.ndarray) – Flux per unit wavelength (f_λ), in any units, and its 1σ error in the same units.

  • mjd (float) – The MJD of the visit, in days.

  • mask (numpy.ndarray, optional) – True for pixels to ignore.
