iter_spectra¶

strider.io.iter_spectra(path: str | PathLike, columns: dict[str, str] | None = None, wavelength_unit: str = 'angstrom', flux_density: str = 'f_lambda') → Iterator[tuple[str, Transient | str]][source]¶

Read a table of spectra one transient at a time, so that a table of any size can be classified.

The table is a parquet file with one row per visit, its wavelength, flux and error given as lists, or one row per pixel, each of them a number. With one row per pixel, the rows with one visit_id are one visit, or, without that column, the rows with one mjd. The rows of each object must be together; sort the table by object id first if they are not.

Parameters:

  • path (str or path-like) – The parquet file.

  • columns (dict of str to str, optional) – The file’s name for any of STRIDER’s columns that it names differently, such as {"object_id": "SNID", "error": "flux_error"}.

  • wavelength_unit (str) – angstrom, nm or micron.

  • flux_density (str) – f_lambda, flux per unit wavelength, or f_nu, flux per unit frequency, in any units. f_nu flux and errors are converted to f_lambda on a common scale.

Yields:

tuple of str and (strider.Transient or str) – Each object id and its transient, or the reason it cannot be read.

Raises:

ValueError – If a column is missing, a row has no object id, or an object’s rows are not together.
