# Documentation

The current public reading path is deliberately short:

1. [`start_here.md`](start_here.md) — one measured object through STRIDER.
2. [`architecture.md`](architecture.md) — scientific and API boundaries.
3. [`data_and_models.md`](data_and_models.md) — data, reference-bank and model
   provenance.
4. [`reproducibility.md`](reproducibility.md) — guarded evaluation sequence.
5. [`nersc.md`](nersc.md) — concise NERSC commands.

[`calibration.md`](calibration.md) gives the detailed calibration contract.
[`roman_reference_design.md`](roman_reference_design.md) records the scientific
question behind the current candidate.

The other documents preserve experiment decisions, results and earlier
architectures. They remain useful provenance, but they do not define the current
tool. [`research_history.md`](research_history.md) explains how to interpret
them.
