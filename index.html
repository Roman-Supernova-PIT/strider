STRIDER¶

STRIDER identifies transients from their Roman prism spectra. For each transient it gives the probability of each class, the redshift with its range, and how clearly the best match beats the others.

How it works¶

STRIDER combines the visits into one spectrum and compares it with each class at every redshift. It also compares how the brightness in four bands changes between visits with each class. How STRIDER works explains each step.
